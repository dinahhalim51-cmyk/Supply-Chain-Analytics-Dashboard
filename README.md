# Supply Chain Analytics Dashboard

## Project Overview

This project analyzes supply chain performance using Power BI.

The dashboard provides insights into inventory, revenue, products sold, shipping costs, lead time, transportation modes, production volume, inspection results, routes, and locations.

## Dashboard Preview

![Supply Chain Dashboard](Screenshot%202026-09-22%20233322.png)

## Key Insights

- Track total stock levels and total products sold.
- Monitor total revenue and average shipping cost.
- Analyze average lead time across the supply chain.
- Compare products sold and revenue across different locations.
- Analyze transportation modes used for product delivery.
- Compare revenue across different product types.
- Monitor product inspection results.
- Analyze shipping time and production volume by product type.
- Compare product distribution across different routes.

- Interactive location filtering
